4. グループ内部の流れ（ETH・BSC）

5アドレス同士の 直接送金は、ETH・BSC のどちらにも存在しない（X・A8・W5 は両チェーンで未使用のため当然でもある）。間接的な接点は1つだけ：AF（2026-06-09）と C8（2026-08-14）が、同じ配布元 0x11Bf2e0d… から同じ数量 AICC 17,500 を受け取っている。これはグループ内送金ではなく、共通のエアドロップ／配布元から別々に受け取ったものとみるのが自然である。なお AF・C8 の双方が MetaMask 系の仕組み（AF＝DeleGator スマートアカウント、C8＝MetaSwap 経由のスワップ）を使っている点は、運用ツールの共通性を示唆する。

6. カバレッジの限界（正直な注記）

・BSC の取引履歴は取得できなかった。bsc.blockscout.com というインスタンスは存在せず（404）、BscScan API はキーなしアクセスがボット遮断され、Routescan は chainId 56 非対応だった。このため BSC については「存在・nonce・現在残高」までで、AF の BSC での16件の送信の日時・相手・金額は未確認である。
・BSC の X・A8・W5・C8 については、RPC で「残高ゼロ＋送信ゼロ＋主要トークンゼロ」までを確認したもので、受領のみの履歴を 100% 否定するものではない。ただし残高が全てゼロである以上、意味のある資金が残っていることはない。
・Mayan 転送の宛先チェーン／受取人の解決、AF のスパム的トークン（AICC・ETHG）のバッチ内での最終的な行き先は、無料ルートでは追い切れなかった。
・本ページの数値は全て 2026-11-01（JST）時点の実クエリ結果であり、取得できなかった履歴を推測で補ってはいない。
